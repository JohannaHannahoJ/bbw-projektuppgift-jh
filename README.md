## Installation

Initiera npm-projekt:
```
npm init -y
```

Installera paket:
```
npm install express cors dotenv jsonwebtoken bcrypt pg
```

Installera nodemon:
npm install nodemon --save-dev

Kör projektet:
```
npm run serve
```
